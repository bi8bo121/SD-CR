# README figures

The six JPEG files are unmodified copies of the figures in the author-provided revised SD-CR manuscript. Descriptive filenames are used for the repository page.

| Repository file | Manuscript source | Paper layout | README width |
| --- | --- | --- | --- |
| `motivation.jpg` | `1.jpg` | Single column | 48% |
| `framework.jpg` | `2.jpg` | Full width | 100% |
| `fusion-comparison.jpg` | `3.jpg` | Full width | 100% |

| `object-detection.jpg` | `8.jpg` | Single column | 48% |
| `semantic-segmentation.jpg` | `supp9.jpg` | 0.9 × full width | 90% |

The manuscript uses `cas-dc`: a 173.8 mm text area and an 18 pt column gap give a single-column/full-width ratio of approximately 48.2%, rounded to 48% for the README. Figure aspect ratios are preserved.

The three `badge-*.svg` files are local navigation badges, so the README does not depend on an external badge service.
